# Contributing

## Development

- Use Python 3.14 or a compatible Python 3 release.
- Run `python server.py` for terminal development.
- Run `python launcher.pyw` for the windowed desktop launcher.
- Keep changes focused and test both desktop and mobile browser layouts.

## Pull requests

Describe the behavior change, include testing steps, and avoid committing generated thumbnails, caches, virtual environments, build output, or personal media.
